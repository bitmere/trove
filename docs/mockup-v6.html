Token system

Paper #FFFFFF — canvas, interface disappears Ink #171717 — nearly all text Muted #6E6E6E — secondary text Hairline #E7E7E7 — row separators Jade #00A67E — the one accent: ready, progress, play Glass rgba(255,255,255,.72) — floating action cluster only

Type: Space Grotesk for the wordmark and the big percent numerals, Inter for everything else — not Inter-only. Layout primitive: a flat list on hairlines; progress is a 3px track under each row, never a card. Signature move: the right-hand status column — one word or one number per row (Ready / 62% / Queued) — plus the play button on ready rows. What changed in v6: the bottom nav is gone entirely. This app has one primary destination — the Downloads list — so per Material 3 (under 3 destinations use tabs, not a bottom bar; Settings is not a primary destination) and One UI (Viewing Area on top, Interaction Area in the bottom half; screen categories as subtabs at the top), Torrents / Web / Usenet are top subtabs, Search is a field at the top of the list, and Settings, accounts and providers live behind the avatar. The floating liquid glass survives as an action cluster in the thumb zone, bottom-right: a jade + for Add and a smaller glass magnifier that jumps to search (One UI 9.5 pattern). Play is still dynamic: tapping it hands the stream link to Android's chooser, so Nuvio, VLC, MX Player, or any player that opens a link works. A third frame shows that chooser. Rejected: a 2-item Downloads / Search bottom nav — still a nav bar for one real destination, and Search is a field, not a destination.

What the latest TorBox API allows

Checked live against the OpenAPI spec — still v1 (OpenAPI 3.1.0, base https://api.torbox.app); there is no v2. Play: GET /v1/api/stream/createstream (id, file_id, type, chosen_subtitle_index, chosen_audio_index, chosen_resolution_index, scrobbling_enabled) + getstreamdata returns a stream link any player can open — this is the playback path, preferred over requestdl for Play. Add: async creates (asynccreatetorrent / asynccreatewebdownload / asynccreateusenetdownload) return immediately and process in the background, so adding feels instant. More: batch requestdl (GET and POST) for several files at once; RSS feeds (add / list / items / control); integrations that export to Dropbox, Google Drive, OneDrive, Gofile, Pixeldrain and 1Fichier with job status; notifications; user stats and subscriptions; speedtest. Latest changelog: v9.3.1 (2026-11-09) — web-download fixes, uncached torrents more reliable; v9.3 (2026-11-04) — buffering and slow-download fixes; v9 — NNTP direct Usenet, AirLock, T3, WebDAV, tags.
