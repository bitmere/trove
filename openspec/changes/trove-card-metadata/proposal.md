# Useful download card metadata

Replace the format-only cover with a poster, proper media title, year and type.
Parse release names locally and enrich using keyless Cinemeta; ambiguous or failed
lookups retain the parsed label. Keep kind/status, original filename (two lines
with ellipsis), transfers, details and playback. No credentials, new permissions,
dependencies, version bump or streaming API changes.

See validation.md for investigation, sources, scope decision and design tokens.
