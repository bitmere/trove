# Publish Trove on bitmere GitHub Releases

Use [Trove GitHub Releases](https://github.com/bitmere/trove/releases) for
signed APKs and manual update discovery. Keep the installed package
`app.trove.debrid`, add a locally persisted Stable/Beta choice, and require
a clean installation when migrating from an older signing key. This change
supersedes the distribution and metadata contract in the historical updater changes.
